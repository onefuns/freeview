# Roam WiFi Store HTML Preview

이 프리뷰는 에그라우터 Telegram Mini App 쇼핑몰의 공식 프론트 검토본이다. 대응 개발명세는 `../project-spec/STOREFRONT_SPEC.md`, 통합 버전과 변경이력은 `../project-spec/VERSION.md`, `../project-spec/CHANGELOG.md`를 따른다.

LTE/5G 라우터, 포켓 와이파이, 데이터 eSIM 고객 쇼핑몰을 시연하기 위한 독립형 HTML 프리뷰입니다.

## 실행 방법

### 파일 직접 열기

`index.html`을 더블 클릭하거나 브라우저로 열면 됩니다. 해시 라우팅을 사용하므로 별도 서버 없이 주요 기능을 사용할 수 있습니다.

### 정적 서버 사용

원하는 정적 파일 서버의 루트를 `html-preview`로 지정한 뒤 `index.html`을 엽니다. npm 설치나 빌드 과정은 없습니다.

## 포함된 시연 기능

- 설명·홍보 중심 메인과 3종 자동 롤링 배너
- 설명형 매거진·검색형 카탈로그·풀 비주얼 캠페인으로 구조가 완전히 다른 3종 레이아웃 전환
- 판매점 브랜드·오션 블루·포레스트 민트·선셋 코랄 컬러셋
- 라이트·다크 테마 조합 비교
- Alpha/Nova 화이트라벨 전환
- Light/Dark 테마 전환
- 상품 검색, 카테고리 필터, 가격 정렬
- 실사형 여행 배너와 모델별 라우터·eSIM 상품 이미지
- 상품 옵션·수량 선택과 판매점별 장바구니
- 평균평점·별점 분포·키워드 칩·구매인증을 포함한 소셜 커머스형 리뷰
- 배송 방식과 결제수단을 포함한 모의 주문
- 네이버페이·카카오페이·무통장입금·TON·USDT TRC20 5종 결제 UI
- Telegram 상담 결제대기와 TON·USDT 온체인 확인중 상태 시연
- 공지사항, FAQ, 이용약관과 개인정보처리방침 화면
- 주문 완료 및 주문 내역 반영
- MY, 내 기기, 데이터 충전, SIM 재발급 시연
- 공지사항, 사용 가이드, 고객 지원 안내
- 프리뷰 전용 localStorage 복원 및 초기화

실제 지갑 연결, 결제, 송금, 배송 접수, 통신 개통, Telegram 상담, 로그인 또는 관리자 기능은 포함하지 않습니다. 표시된 정책문서는 UI 검토용 샘플이며 운영 전 법률 검토가 필요합니다.

## 저장 데이터

- 모든 저장 키는 `roam-html-preview-` 접두사를 사용합니다.
- 판매점별 장바구니와 모의 주문이 분리됩니다.
- DEV PREVIEW 메뉴에서 프리뷰 전용 데이터만 초기화할 수 있습니다.
- 저장소가 비활성화돼도 현재 세션의 메모리 상태로 동작합니다.

## 시연 범위 안내

상품 사양, 금액, 데이터 잔량, 만료일, 주문 및 배송 상태는 모두 프리뷰용 샘플입니다. 실제 제품 사양이나 판매·통신 조건을 의미하지 않습니다.
