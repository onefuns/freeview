# 에그라우터 통합 프리뷰

기존 라우터 판매관리 업무와 Telegram Mini App 쇼핑몰을 함께 검토하기 위한 정적 HTML 프리뷰 저장소입니다.

## 바로 보기

- `index.html`: Telegram Mini App 쇼핑몰 프론트 프리뷰
- `admin.html`: 대리점·판매점·영업점 통합 관리자 프리뷰
- `assets/`: 쇼핑몰 프리뷰용 실사형 제작 이미지
- `docs/ADMIN_SPEC.md`: 관리자 개발명세
- `docs/STOREFRONT_SPEC.md`: 쇼핑몰 개발명세
- `docs/VERSION.md`: 통합 버전 현황
- `docs/CHANGELOG.md`: 통합 변경이력

## 현재 버전

- 쇼핑몰 개발명세: `v4.8.0-draft`
- 쇼핑몰 프리뷰: `v4.8.0-preview.1`
- 관리자 개발명세: `v4.6.0-draft`
- 관리자 프리뷰: `v4.6.0-preview.1`

모든 상품, 고객, 주문, 가격, 리뷰와 상태 정보는 UI 검토용 목업 데이터입니다. `assets/`의 상품 이미지는 실제 제조사 공식 사진이 아니라 공개 제품 외형을 참고해 제작한 프리뷰용 이미지이며, 운영 배포 전 정식 상품 이미지로 교체해야 합니다.
