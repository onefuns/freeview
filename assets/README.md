# 프리뷰 이미지 에셋

이 폴더의 PNG 이미지는 쇼핑몰 UI 검토를 위해 OpenAI 내장 이미지 생성 도구로 제작한 프리뷰 전용 이미지다.

- `hero-travel-router.png`: 공항 라운지 라우터 사용 장면
- `product-mxr5gax.png`: 공개 제품 사진을 찾기 어려운 모델의 일반형 5G 휴대 라우터 이미지
- `product-cnr5g500.png`: 공개된 CNR-5G500 외형·포트·LED 구성을 참고한 이미지
- `product-k100w.png`, `product-l580w.png`: 공개된 설치형 LTE 라우터 외형·포트 구성을 참고한 이미지
- `product-jt201-egg.png`: 공개된 JT201 휴대형 외형을 참고한 이미지
- `product-data-esim.png`: 디지털 eSIM 개통을 표현한 라이프스타일 이미지

실제 제조사 공식 상품 사진이 아니며 제품 사양·색상·구성품을 보증하지 않는다. 운영 배포 전 판매자가 보유한 정식 상품 이미지로 교체해야 한다.
